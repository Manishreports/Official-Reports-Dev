# Official Reports V3.1

## Inventory dashboards
- ECOM & DROS Stock upload added.
- Complete Inventory Dashboard.
- Offline Inventory Dashboard.
- Signature Inventory Dashboard.
- Online Inventory Dashboard.
- Dashboard grouping is by unique Total Stock `Plant Name` (dashboard Location).
- Region from `REGION NAME`, Area from `AREA`, Code from `Plant`.
- New locations prompt for a unique remembered display order.
- Region and Area can be independently hidden before preview/download.
- Four dashboards download in one formatted Excel workbook.

## Logic
- Complete dashboard separates Signature category from other Total Stock KG.
- ECOM + FK01 feed Online columns.
- DROS feeds separate Dros columns.
- Online dashboard includes ECOM + FK01 + DROS.
- Offline dashboard uses complete Total Stock KG.
- Signature dashboard uses Category containing Signature.
