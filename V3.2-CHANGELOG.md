# Official Reports V3.2

## Inventory dashboard workflow
- Location order popup no longer opens during Total Stock upload.
- Location order is requested only when an Inventory Dashboard is opened.
- Bulk copy/paste order editor supports `Order<TAB>Location` or `Location<TAB>Order`.
- Saved Location order remains in browser storage.
- All inventory dashboard values are rounded to whole numbers.
- Inventory dashboards are opened from Workspace > Reports Dashboard, not from the sidebar.

## System Overview
- Added Offline Stock table: Plant Name, Stock (KG), Transit (KG).
- Added Online Stock table: Plant Name, Stock (KG), Transit (KG).
- Both tables have 5 / 10 / 50 row selectors.
- Status & Activity moved to the bottom of System Overview.

## Excel color preservation
- Added ExcelJS-based Description-cell style reader.
- Red/yellow Description fills from Total Stock source are carried to Plan & HO and Plan & Supply downloads.
- SheetJS fallback remains available.
